Escribe una pregunta para consultar la base de datos empresarial.

SQL Generado por la IA:

SELECT p.nombre_producto, SUM(v.cantidad) AS total_ventas
FROM VENTAS v
JOIN PRODUCTOS p ON v.id_producto = p.id_producto
WHERE YEAR(v.fecha) = 2025
GROUP BY p.nombre_producto
ORDER BY total_ventas DESC LIMIT 5;
