¿Cuánto vendimos por mes en el primer trimestre de 2025?

Ventas del trimestre

S/ 2,405
EneroS/ 347
FebreroS/ 844
MarzoS/ 1,214
Ver consulta SQL 
SELECT DATE_FORMAT(fecha_venta, '%Y-%m') AS mes,
       SUM(total_importe) AS total
FROM ventas
WHERE fecha_venta >= '2025-01-01'
  AND fecha_venta < '2025-04-01'
GROUP BY mes
ORDER BY mes;
