03
Administrador o usuario

Haz tu pregunta en lenguaje natural.

Elige la fuente y describe qué necesitas saber. Incluye el período y la forma de agrupar la información cuando sean relevantes.

La IA genera el SQL utilizando el esquema configurado. Antes de ejecutarlo, QueryBI revisa las operaciones solicitadas y los elementos de la base que utiliza.

Tu pregunta

¿Cuánto vendimos por mes entre enero y marzo de 2025?
Revisar el SQL del ejemplo 
SELECT DATE_FORMAT(fecha_venta, '%Y-%m') AS mes,
       SUM(total_importe) AS total
FROM ventas
WHERE fecha_venta >= '2025-01-01'
  AND fecha_venta < '2025-04-01'
GROUP BY mes
ORDER BY mes;
04
Administrador o usuario

Explora los resultados y conserva el análisis.

La consulta validada se ejecuta sobre la fuente. Revisa la tabla, los indicadores y el gráfico para comprender la información obtenida.

Guarda un reporte o vuelve al historial para consultar la pregunta, el SQL y el resultado de tus análisis.

¿Necesito saber SQL para hacer preguntas?

Puedes preguntar en lenguaje natural. El SQL está disponible para que las personas con conocimientos técnicos puedan revisarlo y comprender el análisis.

¿Tengo que copiar mi base de datos a QueryBI?

Conectas una base existente mediante sus datos de acceso. La información permanece en su servidor de origen, que debe permitir una conexión autorizada desde el servidor de QueryBI.

¿Todos los usuarios pueden configurar las fuentes?
