Quiénes somos

Grupo 04

Somos un equipo de estudiantes del curso de Aplicaciones Distribuidas I. Nuestro proyecto propone facilitar la consulta de datos empresariales mediante lenguaje natural.

Esta primera entrega presenta las interfaces de QueryBI AI utilizando HTML, CSS y JavaScript.

Misión

Facilitar el acceso a información empresarial mediante una interfaz clara para consultar, visualizar y comprender datos.

Visión

Desarrollar una herramienta accesible y confiable que apoye decisiones informadas a partir de datos autorizados.

Nuestros principios

  • Claridad en la presentación de información.
  • Acceso responsable a los datos.
  • Trazabilidad de las consultas realizadas.
